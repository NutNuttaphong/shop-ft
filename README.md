# คู่มือการใช้งานระบบ สบายดีมาร์เก็ต (Sabaidee Market) 🛒

ยินดีต้อนรับสู่ **สบายดีมาร์เก็ต** ระบบร้านค้าออนไลน์และจัดการคลังสินค้าแบบ Modular Architecture ที่ถูกออกแบบโดยคำนึงถึงความสะดวกในการใช้งานของผู้ใช้อายุ 30-50 ปี (การจัดวางเนื้อหาที่กว้างขึ้น เมนูปุ่มขนาดใหญ่ขึ้น การสเกลขนาดตัวอักษรเพื่อช่วยอ่าน และระบบการชำระเงินที่เข้าใจง่าย)

---

## 🔑 บัญชีผู้ใช้งานสำหรับทดสอบระบบ (Login Credentials)

เพื่อความสะดวกในการทดสอบ มีปุ่ม **"ดึงข้อมูลเข้าสู่ระบบด่วน"** ที่หน้าจอเข้าใช้งาน หรือท่านสามารถพิมพ์ข้อมูลดังต่อไปนี้:

| ประเภทผู้ใช้ (Role) | ชื่อผู้ใช้งาน (Username) | รหัสผ่าน (Password) | สิทธิ์และการแสดงผลเมนู |
| :--- | :--- | :--- | :--- |
| **ลูกค้า (User)** | `user@1234` | `user@1234` | มองเห็นหน้าซื้อสินค้า (Product Shop) และ ตะกร้าสินค้า (Cart) |
| **ผู้ดูแลระบบ (Admin)** | `admin@1234` | `admin@1234` | มองเห็นหน้าสรุปยอด (Dashboard) และ หน้าจัดการคลังสินค้า (Manage Products) |

## 🛠️ วิธีการติดตั้งและรันโปรเจค (Installation & Running)

โปรเจคนี้พัฒนาขึ้นด้วยเทคโนโลยี **Vite + React + TypeScript + Tailwind CSS**

### 1. การติดตั้ง Dependencies
เปิดเทอร์มินัลในโฟลเดอร์ของโปรเจคแล้วรันคำสั่ง:
```bash
npm install
```

### 2. การเปิดเซิร์ฟเวอร์สำหรับพัฒนา (Development Server)
รันเซิร์ฟเวอร์จำลองการทำงานบนเครื่องของท่าน:
```bash
npm run dev
```
หลังจากรันคำสั่งเรียบร้อย ระบบจะเปิดโปรเจคที่ลิงก์: [http://localhost:5173](http://localhost:5173) (หรือตามพอร์ตที่ระบุบนหน้าจอ)

### 3. การสร้าง Build สำหรับขึ้นใช้งานจริง (Production Build)
```bash
npm run build
```

## 📂 โครงสร้างการจัดเก็บไฟล์ (Modular Folder Structure)

โปรเจคนี้จัดเรียงแบบ **Feature-based/Modular Structure** เพื่อความเป็นระเบียบและสเกลระบบได้ง่าย:

```
src/
├── app/                     # การตั้งค่าหลักของ Application
│   ├── providers/           # context providers / layout wrapper
│   ├── router/              # การตั้งค่าเส้นทางของระบบ (Router)
│   └── layouts/
│
├── modules/                 # แยกเป็นโมดูลตามฟีเจอร์ธุรกิจ (Feature/Business)
│   ├── auth/                # ระบบตรวจสอบสิทธิ์ความปลอดภัย (Login, Store, Hooks)
│   ├── products/            # หน้ารายการสินค้าของลูกค้า และ หน้าจัดการสินค้าสำหรับแอดมิน
│   ├── cart/                # ตะกร้าสินค้าและการคิดเงินยอดสั่งซื้อ
│   └── dashboard/           # สถิติและยอดสั่งซื้อหลังบ้านของผู้ดูแลระบบ
│
├── shared/                  # ส่วนประกอบหรือบริการที่ใช้ร่วมกันทั้งระบบ
│   ├── components/
│   │   ├── ui/              # ชิ้นส่วนพื้นฐาน UI (ปุ่ม, ฟอร์ม, การ์ด)
│   │   └── layout/          # Layout หลักของหน้าต่างเว็บบอร์ด (MainLayout)
│   └── services/            # บริการ RestfulApi get และ post (จำลอง Latency และ LocalStorage DB)
│
├── role/                    # ระบบควบคุมสิทธิ์ผู้ใช้ (Role Management)
│   ├── permissions.ts       # การจับคู่สิทธิ์ของแต่ละหน้าเว็บ
│   ├── roles.ts             # นิยามค่า Role (User, Admin, Guest)
│   └── guards/              # อุปกรณ์ป้องกันความปลอดภัยในการเข้าหน้าเพจ (RoleGuard)
│
├── routes/                  # แฟ้มจัดหมวดหมู่เส้นทาง (Routes)
│   ├── public.routes.tsx    # หน้าสาธารณะ (Login, 404)
│   ├── user.routes.tsx      # หน้าสำหรับ User (Catalog, Cart)
│   └── admin.routes.tsx     # หน้าสำหรับ Admin (Dashboard, Manage)
│
├── styles/                  # ไฟล์การแต่งสไตล์หลัก (Tailwind CSS, Font config)
├── App.tsx                  # จุดรวม Routing และ Providers
└── main.tsx                 # จุดเริ่มต้น Render React DOM
```

## ✨ คุณสมบัติเด่นของระบบและดีไซน์ (Key Features & Accessibility)

1. **การปรับขนาดตัวอักษรเพื่อการอ่านง่าย (Accessibility Resize)**:
   มีปุ่มควบคุมที่แถบด้านบน (Navbar) ให้ผู้ใช้งานเปลี่ยนขนาดตัวอักษรได้ 3 ระดับ (ปกติ / ใหญ่ / ใหญ่มาก) ซึ่งจะขยายเนื้อหาทั้งหมดในหน้าเว็บทันที เหมาะอย่างยิ่งสำหรับผู้ใช้งานอายุ 30-50 ปีที่อาจมีปัญหาเรื่องสายตา
2. **ระบบจำลอง RESTful API (Mock Persistence Engine)**:
   ตัวส่งคำสั่ง GET และ POST ใน `src/shared/services/api.ts` จะจำลองดีเลย์เครือข่ายและการบันทึกข้อมูลในฐานข้อมูล `localStorage` ดังนั้น เมื่อ Admin ทำการเพิ่ม/แก้ไข/ลบสินค้า หรือ User ทำการส่งสั่งซื้อและตัดสต็อก สินค้าจะอัปเดตและบันทึกอยู่จริงแม้มีการรีเฟรชหน้าจอเว็บ
3. **การควบคุมการเข้าถึงตามบทบาทผู้ใช้ (Role-based Navigation Guard)**:
   - สกัดกั้นไม่ให้ลูกค้าธรรมดาแอบพิมพ์ URL เพื่อเข้าลิงก์ของ Admin โดยระบบจะดีดกลับไปหน้าช้อปปิ้งของตัวเองโดยอัตโนมัติพร้อมแจ้งเตือนสิทธิ์
   - เมื่อล็อกเอาต์ ระบบจะล้างข้อมูลเซสชันในเครื่องออกทั้งหมดเพื่อป้องกันความปลอดภัย
